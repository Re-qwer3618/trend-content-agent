# 인스타그램 릴스

원천: "채널별 콘텐츠 통합 템플릿" › 인스타그램 릴스 (+ 프로젝트 기존 릴스 지침 agent/prompts/reels.md)

## 콘셉트

- 길이 20~30초, 9:16
- 톤: 문제 해결형 / 비교형 / 사용법형(정리형) 중 하나
- 첫 3초 훅: 시청 중단을 막는 질문 또는 결과 먼저. 후보 3개(질문형 / 숫자·반전형 / 결과 먼저)를 내고 하나를 고른 이유 한 줄
- 핵심 CTA: 프로필 링크 / 저장 / 공유 / 댓글 — 공통 CTA와 일치

## 출연 캐릭터

사용자가 출연 캐릭터(말투·보이스·외형 톤)를 지정한 경우에만 반영하고, 모든 컷에서 얼굴·헤어·의상·색감 일관성 유지를 적는다.
지정이 없으면 "본인 출연 / 화면 녹화 / B-roll" 중 이슈에 맞는 방식을 제안한다. 실존 인물을 생성 영상으로 만들지 않는다.

## 대본·스토리보드 표 (7구간)

| 구간 | 화면·연출 | 내레이션 | 자막 | 이미지·영상 생성 프롬프트 |

- 0~3초 훅 → 3~7초 문제 → 7~12초 해결 시작 → 12~17초 핵심 → 17~22초 결과·변화 → 22~26초 주의 → 26~30초 CTA
- 장면당 핵심 메시지 하나, 자막은 한 줄 14자 이내·최대 2줄, 중앙~상단 1/3(하단 UI 안전 영역)
- 내레이션은 초당 4~5음절 기준으로 분량을 맞춘다
- 생성 프롬프트: **`agent/prompts/visual_rules.md`(생성 프롬프트 규칙)를 먼저 읽고 그대로 따른다** — 영문 한 문단,
  `피사체 → 행동 1개 → Camera: 이름 붙은 무빙 1개(구간별 카메라 사전) → 장소·시간 → Look: 조명·색감·렌즈`, 칸 뒤에 `(N초)`.
  비율(9:16)은 본문이 아니라 생성기 설정. beautiful·cinematic 같은 막연한 말 대신 구체적 조명·렌즈 이름.
- 네거티브(입력 칸이 있는 생성기용, 영문): face warping, duplicate people, extra fingers, unnatural mouth movement,
  frame jitter, outfit or hair change between shots, distorted text, watermark, low resolution
  — 본문에는 "하지 말 것" 대신 원하는 모습("locked-off tripod shot")을 쓴다
- '피해야 할 행동'을 다루는 이슈(안전 수칙 등)는 위험 행동을 따라 하고 싶게 연출하지 않는다

## 캡션·해시태그

캡션: 첫 문장 훅 → 문제와 해결 요약 → 핵심 정보 → 공통 CTA. 해시태그 10~13개(메인·서브·릴스 관련).
