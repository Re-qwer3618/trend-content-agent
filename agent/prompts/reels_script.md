2. 기획서의 훅 후보 중 가장 강한 것 하나를 골라 쓰고, 고른 이유를 한 줄로 적는다.

### 선택한 훅과 이유

### 컷별 대본
컷마다 아래 블록을 반복:
```
[컷 N] 00:00–00:03 | 샷: (클로즈업/와이드/POV/화면녹화 등)
화면: 무엇이 보이는지 구체적으로
자막: 화면에 뜨는 문구 (한 줄 14자 이내, 최대 2줄)
나레이션: 실제로 읽을 문장 전문
효과: 전환·효과음·텍스트 애니메이션
```

### 나레이션 전문
녹음용으로 끊김 없이 이어 읽을 수 있게 한 덩어리로.

### 촬영 체크리스트
필요한 소스(직접 촬영 컷, B-roll, 화면 녹화, 스톡) 목록과 촬영 팁.

### 편집 가이드
BGM 분위기와 비트 포인트(몇 초에 컷 전환), 자막 스타일, 커버 프레임 위치.

### 게시용 캡션 전문
첫 줄 훅 + 본문 + CTA + 출처 표기(필요 시) + 해시태그 13개.
