1. **독자 관점 3~4개 정하기**: 이 키워드를 검색할 사람 유형 (예: 처음 해 보는 사람 / 가족 단위 / 비용에 민감한 사람 / 안전이 걱정되는 사람)
2. **관점별 질문 3개씩**: 그 사람이 실제로 검색창에 칠 만한 구체적 질문 (언제·어디서·얼마·어떻게·주의할 점)
3. **질문마다 근거 찾기**: 웹 검색으로 원문(언론사·기관 공지·공식 사이트)을 확인하고 출처 URL을 기록. 답을 못 찾은 질문은 `[확인 필요]`
4. **개요 다듬기**: 기획서의 소제목에 3단계에서 확인된 답을 배치. 근거 없는 소제목은 빼거나 줄인다
5. **다듬기**: 첫 문단에 글 전체 핵심을 2~3문장으로 요약, 소제목 사이 중복 제거, 숫자·날짜는 원문과 한 번 더 대조

작성 조건

1. **사실 확인**: 데이터에는 기사 제목만 있다. 본문에 쓸 이슈는 위 3단계처럼 웹 검색으로 원문을 확인한 뒤 쓴다.
   기간·요금·장소·예약 방법처럼 확인하지 못한 세부 정보는 지어내지 말고 `[확인 필요: 무엇을]`으로 남긴다.
   (웹 검색 도구가 없으면 제목에 나온 사실까지만 쓰고 나머지는 `[확인 필요]`)
2. **톤앤매너**: 친근하고 정보성 있는 블로그 에디터 톤, 존댓말. 이모지는 소제목·목록 앞에 적절히 (문단마다 남발하지 않기).
3. **SEO**: 기획서의 제목 후보 중 하나를 `#` 제목으로 쓰고, 메인 키워드를 제목·첫 2~3문장·마무리에, 서브·롱테일 키워드를
   `##` 소제목과 본문에 자연스럽게 넣는다. 메인 키워드는 본문에 5~7회, 억지 반복 금지.
4. **구성**
   - 도입부: 최근 이슈를 언급하며 이목을 끌고, 이 글에서 무엇을 알려 줄지 예고
   - 본론: 기획서의 소제목 순서대로, 이슈별 핵심 내용 + 독자가 바로 써먹을 실용 정보(체크리스트·표·팁)
   - **자주 묻는 질문(FAQ) 3개**: 2단계 질문 중 검색량이 많을 만한 것을 골라 `Q.` / `A.` 형식으로 짧게 답 (근거 링크 포함)
   - 마무리: 한눈에 보는 요약 표 + 댓글 유도 질문 1개
5. **출처 표기**: 이슈를 언급한 문단 끝에 `([언론사명](URL))` 형식으로 링크. URL은 데이터의 URL이나 검색으로 찾은 원문 URL만 쓴다.
6. **사진 자리**: 필요한 위치에 `[사진: 무엇을 찍은 사진]`을 넣는다 (4~6곳).
7. 분량: 공백 포함 2,500~3,500자.
