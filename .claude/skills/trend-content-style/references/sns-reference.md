# SNS 레퍼런스 규칙 (인스타 피드·카드뉴스·릴스)

원천: 노션 🎨 디자인 레퍼런스 허브 `카테고리 = SNS/카드뉴스` (data source `collection://8a5b120a-2719-46c7-9d45-8169e3fc99f2`)
— 사용자 스킬 `sns-content-reference`가 관리. 2026-10-11에 12개 행을 이 프로젝트 파이프라인에 맞게 골라 옮겼다.
허브 규칙이 바뀌면 그 스킬로 다시 읽고 이 파일을 고친다. 우선순위는 사용자 지시 > 이 프로젝트 규칙(cards.md·viral.md) > 허브 규칙.

## 기본 조합 (매 세트 시작 때 한 줄로 밝힌다)

`레퍼런스: Behance(흐름·위계) + 미리캔버스(국내 톤·줄바꿈) + Pinterest(시리즈 일관성)` — 수치·비교 장이 많으면 Dribbble(정보 카드)을,
이벤트·행사 공지형이면 망고보드(혜택 → 참여 방법 → 유의사항 → 마감 CTA)를 더한다.

## 카드뉴스 (1080×1350, 4:5)

- **흐름(Behance)**: 훅 → 문제 → 핵심 3~5장 → 요약(저장용) → CTA. 6~10장, 장마다 메시지 하나.
- **위계(Behance)**: 제목 / 강조 / 본문 3단계만. 강조는 *포인트 컬러 하나*로만 — 하이라이트 박스와 같이 쓰지 않는다
  (채널 키트: 표지는 흰 띠, 내지는 주황 글자 — 한 장에 한 곳).
- **국내 톤(미리캔버스)**: 굵은 고딕 제목 + 말풍선 강조 + 해요체. 본문 3~4줄, 한 줄 15~18자, 줄바꿈은 직접 지정(단어 중간 X).
- **표지·시리즈(Pinterest)**: 표지와 내지는 다른 레이아웃(표지 = 큰 제목 + 그림 하나, 내지 = 같은 그리드 반복).
  색·폰트·계정 위치·도전 테이프는 모든 세트에서 고정 → 피드 그리드에서 한 시리즈로 보이게. 마지막 장은 요약 또는 CTA 전용.
  프로필 그리드에선 가운데 3:4만 보이므로 표지 제목을 위아래 끝에 두지 않는다.
- **정보 카드(Dribbble)**: 수치·비교는 숫자를 크게, 표·행 3개 안팎. 상하좌우 여백 64px 이상, 그림자 1단계.
- **글자 크기**: 본문 36px·제목 72px 이상(채널 키트는 본문 34~46, 제목 96~104). 사진 위 글자는 대비 4.5:1 이상.
- **폰트(눈누)**: 최대 2종 — 지금은 Pretendard 1종(OFL, 영상 포함 사용 가능). 새 폰트를 넣으면 영상(릴스) 사용 허용을 확인.
- **사진·아이콘(Unsplash·Pixabay·Flaticon)**: 쓰면 한 스타일로 통일, 출처를 캡션이나 마지막 장에. 인물·상표가 보이는 사진은 홍보에 쓰지 않는다.
- **사실·수치 출처**: 화면 칸 label에 근거, 캡션 끝에 "출처: 매체·날짜" 한 줄.

## 릴스 (1080×1920, 9:16, 30fps)

- **안전 영역**: 위 250px, 아래 420px(캡션·버튼), 오른쪽 120px(좋아요·댓글)에는 글자를 두지 않는다.
  카드형 릴스(`--card-reel`)는 카드를 0.8배로 줄여 가운데(위 300px부터) 두는 `reelsafe` 형식을 쓴다 — 카드 글자와 자막이 이 영역 밖에 온다.
- **자막**: 한 줄 14자 안팎·최대 2줄, 화면 중앙~하단 1/3 **위쪽**(아래 420px 위). 나레이션은 장마다 한 문장, 전체 20~30초.
- **커버**: 그리드에선 가운데 3:4만 보이므로 커버 제목은 화면 중앙부에. 첫 장(표지 카드)이 커버가 된다.
- **B-roll(Pixabay)**: 배경 영상은 세로(9:16) 또는 세로로 잘라도 주제가 남는 것만.

## 캐릭터 이미지

- 한 콘텐츠 안 일러스트·캐릭터는 한 스타일(채널 기본: 펠트 미니어처 인형 사진 톤)로 통일, 사진과 섞지 않는다.
- 주제에 맞는 캐릭터를 쓴다(`agent/prompts/characters.json`의 topics). 없으면 gen을 적어 `run.bat --make-character <id>`로 만든다.
- 실존 인물·구단 로고·팀 색을 흉내 내지 않는다(스포츠는 중립 색 유니폼, 로고 없음). 사실적 인물 이미지는 'AI 정보' 표시.

## 하지 않는 것

- 핀·포트폴리오·템플릿의 사진·일러스트·문구·로고를 가져오지 않는다(구성·위계만 참고).
- 레퍼런스 사이트를 직접 봤다고 말하지 않는다 — 근거는 허브의 적용 규칙 텍스트.
- AI 초안(Mirra 등)을 그대로 게시하지 않는다 — 이 프로젝트는 Claude가 기획·문구를 쓰고 사실을 확인한다.
