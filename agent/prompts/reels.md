다음 구성을 지켜서, 제목 수준은 `###`부터 시작해 줘 (상위 문서에 삽입됨).

### 1. 콘셉트
- 톤 하나: 문제 해결형 / 비교형 / 사용법·정리형
- 영상이 주는 하나의 가치 + 타깃 + 저장·공유하고 싶어지는 이유
- 핵심 CTA 하나: 프로필 링크 / 저장 / 공유 / 댓글
- 출연 방식: 본인 출연 / 화면 녹화 / B-roll 중 이슈에 맞는 것 (실존 인물을 생성 영상으로 만들지 않는다)

### 2. 3초 훅(Hook) 후보 3개
유형을 다르게: ① 질문형 ② 숫자·반전형 ③ 결과 먼저 보여주기형
각 후보마다: 첫 화면 / 화면 자막(12자 이내) / 첫 마디 나레이션 / 왜 스크롤을 멈추게 하는지

### 3. 스토리보드 (7구간)
| 구간 | 화면·연출 | 나레이션 | 자막 | 이미지·영상 생성 프롬프트 |
0~3초 훅 → 3~7초 문제 → 7~12초 해결 시작 → 12~17초 핵심 → 17~22초 결과·변화 → 22~26초 주의 → 26~30초 CTA.
장면당 핵심 메시지 하나. 생성 프롬프트는 맨 아래 **생성 프롬프트 규칙**대로 영문 한 문단:
`[subject + look] [one action, adverb]. Camera: [named move from the 구간 사전]. [place, time of day]. Look: [lighting, color, lens]. caption-safe empty upper third.`
각 칸 뒤에 `(N초)`를 붙인다.

### 4. 시각적 연출 가이드
- 자막: 한 줄 14자 이내·최대 2줄, 중앙~상단 1/3 (하단 UI 안전 영역)
- 촬영 소스(직접 촬영/화면 녹화/B-roll/스톡), 조명, 구도
- 편집: 컷 속도, 전환, 효과음 포인트, 배경음악 분위기(인스타 오디오 라이브러리 기준)
- 커버 이미지와 커버 문구
- 네거티브 프롬프트(입력 칸이 있는 생성기용, 영문 한 줄): face warping, duplicate people, extra fingers, unnatural mouth movement,
  frame jitter, outfit or hair change between shots, distorted text, watermark, low resolution
  — 본문 프롬프트에는 "하지 말 것" 대신 원하는 모습을 쓴다(규칙 참고)

### 5. 캡션 & 해시태그
첫 문장 훅 → 문제와 해결 요약 → 핵심 정보 → CTA, 해시태그 10~13개 (메인·서브·릴스 관련)
