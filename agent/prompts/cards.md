카드뉴스 데이터 규칙 — 피드 카드뉴스 문구를 그대로 PNG로 굽기 위한 JSON (1080×1350, 인스타 캐러셀)

- 장 구성: 8장 안팎(최대 20장). 1 표지(훅) → 2 문제 → 3 공감·흐름 → 4 핵심 정보 → 5 방법·체크리스트(저장용) → 6 얻는 것 → 7 주의 → 8 마무리(CTA).
  한 장에 메시지 하나. 같은 모양이 세 장 넘게 이어지지 않게 화면 칸 종류(rows / list / table / checks / text)를 바꾼다.
- 표지(`cover`): 제목 3줄 이내·줄당 8자 안팎, `*강조*` 한 군데. 화면 칸에 이 세트가 다룰 내용 2~3줄(rows).
- 내지(`page`): `pill`은 장의 역할(예: 왜 궁금할까 / 핵심 정보 / 저장용 / 주의), 제목 2줄·줄당 9자 안팎, 마지막 줄이나 핵심어에 `*강조*`.
- 마무리(`closing`): 공통 CTA 한 문장을 제목으로, 화면 칸에 가져갈 요약(rows 3줄).
- `say`: 카드형 릴스에서 읽을 말 한두 문장(장마다 25자 안팎, 전체 30초 안팎). 카드 글을 그대로 읽지 말고 말하듯 — 예) "텐트 안 난방은 절대 금지예요."
- `desc`는 한 줄(25자 안팎). 화면 칸 글은 줄당 18자 안팎, 3~4줄. 줄을 직접 끊을 땐 `\n`.
- 사실 규칙: 근거는 수집한 기사·영상 제목(과 웹 검색으로 확인한 원문)뿐. 화면 칸 `label`에 근거를 적는다(예: "기사 제목 · 세계일보 10.08").
  확인 못 한 제품명·가격·일정·수치는 `*[확인 필요]*`로 둔다. 예시 화면은 label에 "예시"라고 적는다. 후기·성과·통계를 지어내지 않는다.
- 캐릭터(선택): `host`(덱 최상위)는 진행 캐릭터 id — 릴스의 기본 목소리. 장마다 `speaker`+`line`으로 캐릭터 한마디(20자 안팎)를 넣는다 —
  세트에서 3~4장만, 매 장 넣지 않는다. 한마디가 있는 장은 화면 칸이 낮아지니 화면 칸 글을 3줄(rows·table 3행) 이하로. 이미지가 있는 마스코트는 화면 칸 `character`로 리액션 컷을 쓸 수 있다(표지·반전 장).
  `say`가 있는 장은 그 장의 `speaker` 목소리로 읽힌다. 캐릭터 말투는 아래 명단의 성격을 따른다.
{{cast}}
- 화면 칸 종류(`shot`에 하나만): `rows` [["이름","값"], …] · `list` ["줄", …] · `table` [["머리","값"], …] · `checks` ["체크 항목", …] · `text` "문장(*강조* 가능)" · `character` "캐릭터 id" + `mood`(shock/smile) + `bubble` "말풍선".
  `dark: true`는 표지·마무리에만.
