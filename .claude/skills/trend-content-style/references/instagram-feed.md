# 인스타그램 피드 — 카드뉴스

원천: "채널별 콘텐츠 통합 템플릿" › 인스타그램 피드

## 콘텐츠 기획

- 형식: 단일 이미지 / 카드뉴스(기본 8장)
- 첫 장 훅: 문제·질문·결과 중심의 짧은 문구 (한 줄 14자 안팎)
- 핵심 메시지: 주제와 키워드를 한 문장으로
- CTA: 저장 / 공유 / 링크 방문 / 댓글 중 하나 (블로그·릴스와 같은 공통 CTA)

## 카드뉴스 문구 (장별)

1. 첫 장 — 강한 훅
2. 문제 — 타깃이 겪는 불편·궁금증
3. 공감 — 그 문제가 반복되는 이유
4. 해결 — 이슈의 핵심 정보 (출처 있는 사실만)
5. 방법 — 바로 써먹는 단계·체크리스트
6. 효과 — 알면 얻는 것
7. 주의 — 확인할 점, `[확인 필요]` 항목
8. CTA — 최종 행동 유도

트렌드 이슈에는 "서비스·제품 소개"가 없으므로 4~6장은 "이슈 정보 → 실전 팁 → 얻는 것"으로 바꿔 쓴다.
장당 문구는 모바일에서 3줄 이내, 저장하고 싶은 정보(표·체크리스트)를 한 장 이상 넣는다.

## 카드 이미지 (JSON → PNG)

카드 문구는 `agent/prompts/cards.md` 규칙의 JSON으로도 써서 PNG로 굽는다(SKILL.md "카드뉴스 굽기").
위 8장 흐름을 그대로 장으로 옮기고, 장마다 화면 칸 종류를 바꾼다 — 근거 기사는 `table`, 방법은 `checks`(저장용), 요약은 `rows`.
화면 칸 `label`에 근거(기사 제목 · 언론사 날짜)를 적고, 모르는 제품·가격·일정은 `*[확인 필요]*`.

## 발행용 캡션

첫 문장 훅 → 문제와 공감 → 핵심 정보·방법 → 주의사항·활용 팁 → 공통 CTA

## 해시태그

메인 키워드, 서브 키워드, 관련 검색어 위주 10~15개. 브랜드 태그는 사용자가 정한 것이 있을 때만.

## 이미지 제작 프롬프트

영문 코드 블록: 카드 공통 배경(4:5, 글자 얹을 큰 여백) 1개 + 정보 카드용 배경 또는 아이콘 1개. 작품·인물 카드는 생성 이미지 대신 공식 자료(사용 조건 확인)나 텍스트 카드.

## 검수

종합 판정(발행 가능 / 보완 후 발행 / 보완 필요) — 확인 항목: 첫 장 훅, 장별 흐름, 모바일 가독성, 저장 가치, CTA, 이미지 권리
