형식: 하루·한 주 경기 이슈 하나를 2장(+계정 CTA 1장)으로 짧게 정리. 릴스로 만들면 장마다 한 문장, 15~20초.
1장(표지·훅): 위에 '비교 대상 A · B' 작은 라벨 → 가운데 큰 숫자 하나(예: 'N·N', 'N년 만에') → 한 줄 부제(무엇이 같은지) →
  좌우 두 칸에 같은 항목 3~4줄(이름·소속·핵심 기록), 같은 수치만 포인트 색 → 맨 아래 두 대상을 잇는 반전 한 줄(공통점) → 기준 각주 1~2줄.
2장(근거·마무리): 같은 두 칸으로 비교표 5~6행(배경 → 과정 → 결정적 날짜 → 기록), 공통점 행은 두 칸을 합쳐 강조 →
  맨 아래 두 줄 마무리: 과거 사실 한 줄 + '이번엔 ~에 도전합니다'(다음 경기·기록을 기다리게).
고정 요소: 위 로고(캐릭터 얼굴), 오른쪽 위 장 번호(1/2), 아래 계정 + 슬로건 한 줄, 같은 어두운 배경·같은 포인트 색 한 가지.
계정 CTA 카드: 캐릭터가 엄지 척 + 참여 방법 3칸(무엇을 / 어떻게 보내나 / 보상) — 시리즈 끝에 가끔 붙인다.
캡션: 핵심 한 줄 → 사실 2~3줄 → 응원·질문 → 계정 슬로건 → 해시태그 6~8개(계정명 + 팀 + 주제).
우리 채널로 옮길 때: 실존 선수 사진·구단 로고·팀 색 대신 캐스터(표 정리)·직관이(리액션) 캐릭터와 도형, 기록은 기사 근거 + label에 출처.
